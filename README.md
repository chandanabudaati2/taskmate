Taskmate is a web application built using Python Django and PostgreSQL that helps users manage their daily tasks and to-do lists. Users can sign up, log in securely, add new tasks, update task status, and delete tasks when completed. The application has a clean and responsive interface built with Bootstrap 5, making it easy to use on both desktop and mobile devices. It is also configured for deployment on platforms like Railway.
